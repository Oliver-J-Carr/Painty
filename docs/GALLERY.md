# Gallery

Paintings made with Painty, exported as cards (Export → Card on any painting). Each card shows the title the model gave its painting, the model, the prompt, and what it took to paint.

Have an idea for a painting? [Suggest one](../../issues/new?template=painting-idea.md) and it may end up here.

## Adding a painting

1. In Painty, open the painting in the gallery and choose **Export → Card**.
2. Save the image into `docs/gallery/`.
3. Add it to a table on this page.
